Política de Privacidade da Issa Caixa de Entrada

Atualizada em 13 de novembro de 2026.

Esta política explica como a Issa Caixa de Entrada, ferramenta interna da Issa Consultoria Contábil (ISSA SERVIÇOS CONTÁBEIS LTDA, CNPJ 58.676.332/0001-70), trata os dados que acessa no Gmail.

1. Que dados a ferramenta acessa

A ferramenta acessa somente a caixa de e-mail do próprio escritório, issacontabilidade@gmail.com, com permissão apenas de leitura (gmail.readonly). Dos e-mails, ela usa o remetente, o assunto, a data e os anexos.

2. Para que os dados são usados

Os dados servem para identificar a que cliente pertence cada anexo e salvá-lo na pasta desse cliente, nos computadores do escritório. São documentos que os próprios clientes enviam para a prestação dos serviços contábeis, como extratos bancários, notas fiscais e guias de tributos.

3. O que a ferramenta não faz

  • Não envia, não apaga, não altera e não marca e-mails como lidos.
  • Não vende, não aluga e não compartilha os dados com terceiros para fins comerciais.
  • Não usa os dados para publicidade.
  • Não usa os dados para treinar modelos de inteligência artificial.

4. Onde os dados ficam guardados

Os anexos ficam nos computadores do escritório e no armazenamento em nuvem que o escritório já usa para os documentos dos clientes. A autorização de acesso ao Gmail fica guardada apenas no computador do escritório e não é publicada em lugar nenhum.

5. Quanto tempo os dados ficam guardados

Os documentos são mantidos pelo prazo exigido pela legislação contábil e fiscal para a guarda dos documentos dos clientes.

6. Uso dos dados do Google

O uso e a transferência de informações recebidas das APIs do Google seguem a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado.

7. Como cancelar o acesso

O acesso pode ser cancelado a qualquer momento pela página de permissões da conta Google, em myaccount.google.com/permissions.

8. Direitos e contato

Os titulares de dados podem exercer os direitos previstos na Lei Geral de Proteção de Dados (Lei 13.709/2018), como acesso, correção e eliminação. Dúvidas e pedidos podem ser enviados para issacontabilidade@gmail.com.
